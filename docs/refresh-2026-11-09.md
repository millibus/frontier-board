# Frontier Board refresh — 9 November 2026

## Scope and result

Audit of all **46 pre-existing benchmark columns** and **88 baseline models**, plus verified new releases. This is a full-source audit, **not a claim that every source supplied fresh data**. The publication contains **91 models, 56 columns and 1557 score tuples** (baseline: 88 / 46 / 1,359).

Computed changes: **200 added tuples, 181 updated tuples, 2 removed misattributed tuples**, affecting 84 model rows. New model rows: Arete-27B, Claude Fable 5.2, Muse Ember. Machine-readable before/after values and primary URLs are in `refresh-2026-11-09-changes.json`.

**Preservation rule:** stale, blocked, missing, ambiguous-identity, different-effort and different-evaluator data do not overwrite a previously verified tuple. Source retrieval dates are not automatically evaluation run dates. Archived columns remain archived even when a source-backed omitted row is backfilled.

## Release and source decisions

- **Fable 5.2:** vendor model docs explicitly date release to 9 November 2026 and specify 1M context, standard $8/$40 input/output per million tokens and $0.20 cache reads. Optional fast mode is $16/$80.[1][2][3]
- Its AA **Default Fallback** max-effort run is Index **65**, **$26.54/task**, **101 end-to-end tok/s**, **171.16 seconds to first answer token**, and legacy no-tools HLE **74.28%**. All five effort levels are recorded. HLE-Diamond is a different metric and is not inserted into HLE.[14]
- Fable's ARC2 is **93.8% at xhigh, $0.98/task**, with standard ARC3 **81.17%**. Adapter results—97.27% at xhigh and 97.72% at high—are **not** substituted for the standard score.[16]
- Vals independently reports Fable **65.15% TB4 / 55.71% TB Science**, and Inkling 2 Small **12.63% / 2.86%**. Fable's vendor Science **74.6%** is retained as a distinct run note, not presented as the independent score.[20][21][3]
- **Muse Ember:** Meta explicitly announced muse-ember-1.0 on 9 November. Exact context is 1,048,576 tokens; max output is 524,288. Standard input/output/cache pricing is $0.10/$0.50/$0.004 per million tokens up to 200K input; above that threshold it is $0.30/$1.50/$0.012. AA records Index 36 at max ($0.14/task), with a second xhigh row; Vals TB4 is 39.39%. Unavailable speed/latency remain blank. Ember-1 is a different retained model.[28][29][30][11][20]
- **Agnes Theta:** official identity and pricing are now traceable. Exclusion is due to unverified vendor release date and numerical context—not an untraceable vendor. AA dates alone are not substituted for a confirmed launch.[32][33]
- **Arete-27B:** Nous Research's 6 November announcement and model card establish an open-weight Qwen3.8-27B fine-tune. Its **70% TB2.1** is vendor-run. Training context is not asserted to be maximum inference context; no hosting price or independent score is invented.[6][7]
- Ten new launch-table columns stay separate from older versions: FrontierCode 2.0, FrontierSWE v2, WANDR relaxed, OSWorld 2.1 offline partial, RoboDojo Sim, AA-Briefcase v1.1 rubric, AA-Briefcase v1.1 Elo, Remote Labor Index, HLE with tools and Chartography without tools. All launch-table rows—including competitors and the vendor-quoted AA-Briefcase values—are marked `ven`.[3]
- Removed Fable 5/5.1 ExploitGym tuples because OpenAI's source footnote explicitly attributes those runs to **Mythos**, not production Fable. Fable 5 FrontierMath Tier 4 follows the Astra table's 90.2%, retaining the earlier 87.8% in its note.[8]
- Filled missing Terra HealthBench Professional length-adjusted 62.7, GPT-6 Sol GDPval-AA v2.1 1487, Haiku 4.5 GDPval-AA v2.1 735 and Sonnet 5 FrontierCode 1.1 Main 42.4.[5][9][10]

## Freshness, conflicts and limits

- **AA:** current public data yielded 734 model/effort records. Exact/explicit-alias matches cover 84 baseline models; **Ember-1, Hy4-preview, Doubao Seed 2.1 Pro and ERNIE 5.1** retain their prior AA values. All 60 baseline effort rows were reread, with three additional complete efforts. GPT-6 Luna's intentionally excluded `none` remains excluded. Current method is **v5.0.1**, with CritPt v2 regrading; throughput is end-to-end, not post-first-token speed.[11][12][13]
- AA's 97 review-only alternatives are held: 55 evaluator/effort conflicts, 22 context-specification conflicts, 10 retired LiveCodeBench backfills, five ambiguous zero-price fields and five Nova Preview identity proposals. PRICES are not silently rewritten from AA endpoint pricing.[11]
- **Arena text:** current source blocked. **WebDev:** readable snapshot is 19 October, older than baseline. All 68 text and 72 WebDev tuples and both column dates remain unchanged; this is preservation, not verification of current scores.[22][23]
- **OpenRouter:** current page's last run is 9 November 17:52 UTC; 17 existing scores change and Kimi K3.1 Pro's 75.7% fills an omission. Headline/default-routing or median-provider values are used, not the best provider. Step 3.7 Flash's missing historical row is preserved.[19]
- **MathArena:** all 40 stored values change after the 9 November expected-performance refit. This must not be described as a capability change on a fixed benchmark.[17]
- **WeirdML v3:** 6 November prepared data supplies eight tuple updates/additions. The v2 board snapshot remains archived; the upstream source is not falsely described as universally frozen.[18]
- **Scale:** private means its proprietary 276-task split, not the separate held-out OSS split. Frontier coverage remains stale; the source is undated.[24]
- **OSWorld:** official JSON/XLSX is accessible. The Kimi K2.6 backfill stays in the June task build; v2.1 and alternate author-verified runs are not silently substituted for archived vendor runs.[25]
- **METR:** source states it is no longer actively updated. Recorded suite-specific p50 values are retained.[27]
- Two old SWE-bench figures (Haiku 4.5 70%, Sonnet 4.5 72.8%) were not reproducible in current alternate-harness sources and remain explicitly unresolved rather than silently changed. Historical banking additions retain retrieval/effort/simulator provenance.[26]
- Vendor scan covered all 25 baseline providers plus Nous Research, with explicit partial coverage: several official news/catalog pages are frozen, script-only, blocked, or return a limited recent catalog. A catalog modification date is not a model release date. No claim of an exhaustive absence of other releases is made.
- Gemini 3.8 Flash is **not restored**: PR #12 records the owner's explicit removal request. Tencent's DSpine speculative-decoding checkpoint is not added as a standalone general model. Unverified release candidates remain excluded.

## Verification and update process

Required repository checks: `node scripts/check-data.mjs` and `node scripts/smoke.mjs`, using the existing Chrome binary with Playwright tooling isolated outside the repository. No website dependency or build step is added.

Additional source-contract and browser checks cover exact adopted tuples, all preserved Arena/v4 tuples and dates, five Fable efforts, standard-versus-adapter ARC, Mythos exclusion, vendor/independent quality, model counts, new benchmark cards, all four tabs, and light/dark desktop/mobile rendering. The PR records final executions and current-head review status.

Changes go through a pull request. Per `CLAUDE.md`, wait for Codex's review on the final head and resolve/answer every finding before merging. Merging updates `main`; Pages builds automatically. Verify the resulting deployment and served `index.html` against the merged commit before calling the update live.
